# Explanation Variability in Text Classification: Humans vs. LLMs

The HumanSvsLLMS notebook contains the code needed to produce the analysis and plots presented in the Computational Linguistics paper by Bogaert, Escouflaire et al. (2026). The ModelsTraining_ExplanationsGeneration notebook can be used to re-train the equivalent models and re-generate the explanations needed for the analysis.

To cite this paper or code: Bogaert, J., Escouflaire, L., de Marneffe, M. C., Descampe, A., Standaert, F. X., & Fairon, C. (2026). Explanation Variability in Text Classification: Humans vs. LLMs. *Computational Linguistics*.
